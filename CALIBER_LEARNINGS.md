# Caliber Learnings

Accumulated patterns and anti-patterns from development sessions.
Auto-managed by [caliber](https://github.com/caliber-ai-org/ai-setup) — do not edit manually.

- **[pattern]** Roku resume/play-from-position: seek on the FIRST `state="playing"` transition guarded by a one-shot flag (also covers the transcode-fallback PlayHls path). Make `resumeSeconds` an OPTIONAL arg (guard invalid/≤0 → 0) so music/other callers that omit it play from the start.
- **[gotcha]** Endpoint paths follow TWO conventions — verify which the deployed box serves before changing a client path: continue-watching is `/api/v1/me/continue-watching` (daemon) AND `/api/v1/users/me/continue-watching` (WebPortalRouter); the favorites LIST is `/api/v1/users/me/favorites` (the `/users/me/...` form, NOT `/me/favorites`).
- **[gotcha]** Search is `GET /api/v1/media?search=<q>` (Bearer) — there is NO `/api/v1/search` route. It matches `name` ONLY, enforces NO min length server-side, and IGNORES `topLevel` when `search` is set, so a search spans ALL libraries and CAN return `season`/`episode` rows. Same `{items,total,limit,offset}` envelope as browse.
- **[gotcha]** Do NOT reuse `getLibraryItems` for a global search — it ALWAYS emits `libraryId=<id>&topLevel=1` (or `parentId` mode). Add a dedicated method that omits libraryId/parentId/topLevel + a matching op branch in `ApiTask.ExecRequest`.
- **[gotcha]** A custom focus state machine over sibling SceneGraph nodes must CONSUME (`handled=true`) every directional key while a zone is entered, AND check intra-zone nav FIRST/gated on the current zone so those keys still bubble to grids in OTHER zones. Framework key bubbling between Buttons/PosterGrids is DEVICE-UNVERIFIABLE — own the input defensively and flag it for device QA.
- **[convention]** Components live in top-level `components/` (git-mv'd out of `source/components/`); `bsconfig.json` globs `manifest + source/**/*.brs + components/**/*.{brs,xml} + images`. Keep new scene files under `components/`, not `source/components/`. (CLAUDE.md still says `source/components/` — it is stale; trust the actual tree.)
- **[convention]** Each NEW component `.xml` must `<script>`-include its FULL source closure — a component scope does NOT auto-include `pkg:/source`. Copy the exact 5-line block from the closest scene (`pkg:/source/lib/Storage.brs`, `Utilities.brs`, `ApiClient.brs`, `AppContext.brs`, then its own `pkg:/components/<Scene>.brs`). A missing include is a runtime "function not found" that `bsc` does NOT catch.
- **[gotcha]** Cross-component callable subs MUST be declared in the component `<interface>` as `<function name="LoadFoo"/>` — a `scene.LoadFoo(...)` call from another scene fails at runtime without it and `bsc` does NOT catch it. A scene that a PARENT creates+appends+focuses and self-loads on `Init` (e.g. HomeScene self-creating MusicScene) needs NO `<interface><function>`; only entry-points invoked as `scene.Method(...)` from another scene require declaration.
- **[fix]** When `bsc` fails BS1140 "Cannot find function '<Helper>'" because a shared helper was defined in a module-specific file the caller doesn't include, MOVE the helper into `source/lib/Utilities.brs` (commonly script-included) rather than adding the niche file to every include list. Delete the original to avoid a duplicate-declaration error.
- **[gotcha]** `roUrlTransfer`'s synchronous `GetToString`/`PostFromString` do NOT expose the HTTP status code. To read `GetResponseCode()` go async: `SetPort` + `AsyncGetToString`/`AsyncPostFromString`, then a bounded `wait(<ms>, port)` for an `roUrlEvent`; set `RetainBodyOnError(true)`. `wait(0, port)` blocks FOREVER and `SetTimeout(ms)` bounds the transfer, NOT the `wait()`.
- **[gotcha]** BrightScript's default numeric type is a 32-bit Integer, so `Int(seconds * 10000000)` for 100ns ticks OVERFLOWS past ~214s. Track position in SECONDS (Float) and convert at the API boundary via a Double-math helper returning `LongInteger`.
- **[pattern]** Bound any SceneGraph repeat-`Timer` poll loop with an explicit counter (reset on start, stop + surface error past a cap). A poll that only stops on ready/failed spins forever if the job hangs.
- **[gotcha]** The media-item `runtime` field is in MINUTES (`ticks/600000000`), NOT seconds — multiply by 60 before `FormatTime`. When a scout/Explore agent reports a field's units, treat it as a hypothesis and prefer a convention already verified against server source.
- **[pattern]** Roku on-screen search: `Keyboard` node + `ObserveField("text", ...)`, debounce via a NON-repeating `Timer` restarted on each keystroke (`stop` then `start`); fire the API op only on the Timer `fire`, and RE-READ `m.keyboard.text` inside the fire handler (the keystroke value is stale). Gate on trimmed length ≥ 2 in BOTH handlers.
- **[pattern]** When adding a browse screen that mirrors an existing one, copy the closest template's grid-build + type-routed selection idiom verbatim, back the CURRENT list with `m.rows` (rebuilt per mode/filter so `itemSelected` index maps to the right object), and pair EVERY `ObserveField` in `Teardown`. `back` calls `Teardown()` + `m.top.Close()` per the SearchScene/SeriesScene/SeasonScene precedent.
- **[pattern]** Verify a music/album scene against the bsc gate with `npx brighterscript@0.72.5 --project bsconfig.json` and grep the log for `error|warn` (EXIT=0 + "clean" = pass). This is the ONLY real static gate — `make lint`/`make test`/CI never fail.
- **[convention]** When staging a feature commit, `git add` the specific source files individually — do NOT `git add .` — so untracked tooling dirs like `.claude/skills/` stay out of the commit.
- **[gotcha]** Photo routes are `GET /api/v1/photo/*` — SINGULAR (`/photo/albums`, `/photo/albums/{id}`), NOT `/photos/`. JSON routes are Bearer-gated and `library_id` is REQUIRED (400 if omitted) on albums/albums/{id}/photos/slideshow; album `id` = md5(date). `getPhotoAlbums`/`getPhotoAlbum` return the WHOLE envelope (`{albums:[...]}` / `{album:{...}}`) — the scene reads the named key (mirror getAlbums). The image-byte routes (`/thumbnail`,`/full`) take a SIGNED-URL token, NOT a Bearer.
- **[pattern]** Photo `thumbnail_url`/`full_url` and album `cover_photo.thumbnail_url` are ABSOLUTE + SIGNED (token embedded) → drop them VERBATIM into PosterGrid `HDPosterUrl` / `Poster.uri` (NO Bearer, NO URL building), with `pkg:/images/placeholder.png` fallback when invalid/empty. Guard a nested object like `cover_photo` with `type(x) = "roAssociativeArray"` (mirroring the `type(x)="roArray"` guard for lists) before reading its fields.
- **[pattern]** A scene that observes NO fields (e.g. a full-screen viewer driven entirely by OnKeyEvent left/right/back) needs NO Teardown — only scenes that register `ObserveField` need the Teardown/`UnObserveField` pairing. Its OnKeyEvent must still handle `back`→`m.top.Close()` and return `handled=true` on the keys it consumes.
- **[pattern]** Pass a list between scenes as a render-thread function argument (`scene.LoadPhotos(m.photos, startIndex)`), NOT a node field write — by-reference within the render thread, avoiding Task thread-boundary serialization. Only assocarray/string/number data may cross an ApiTask thread boundary.
- **[gotcha]** A custom focus state machine over sibling SceneGraph nodes must CONSUME (`handled=true`) every directional key while a zone is entered, AND check intra-zone nav FIRST/gated on the current zone (`m.currentRail = "search"`) so those keys still bubble to grids in OTHER zones. Centralize zone re-entry in a helper (e.g. `FocusHeaderZone()`). Framework key bubbling between Buttons/PosterGrids is DEVICE-UNVERIFIABLE — own the input defensively and flag it for device QA.
- **[gotcha]** Do NOT both delegate a slice to a subagent AND hand-implement the same slice in the coordinator — they race / produce no-op duplicate work. In this F7a session the coordinator wrote every file (ApiClient/ApiTask/Utilities + 3 new scenes + HomeScene), passed the bsc gate, AND THEN spawned a general-purpose agent to "implement F7a" which had nothing left to do. Decide ONCE up front: delegate the impl OR do it inline, never both.
- **[pattern]** The clean way to combine subagent review with coordinator edits: instruct the review subagent "Do NOT modify any code — review only" and have it APPEND findings to the worklog; the coordinator then applies fixes itself and re-runs the bsc gate. This sidesteps the same-file race entirely.
- **[pattern]** When adding a browse screen that mirrors an existing one (PhotosScene ⟵ LibraryScene; PhotoAlbumScene ⟵ MusicAlbumScene), copy the closest template's grid-build + index-guarded selection idiom verbatim, back the CURRENT list with `m.albums`/`m.photos`/`m.rows` (so `itemSelected` index maps to the right object), and pair EVERY `ObserveField` in `Teardown`. `back` calls `Teardown()` + `m.top.Close()`.
- **[pattern]** Mirror the `type()` guard for ARRAYS: before caching/iterating a server list field, gate on `type(x) = "roArray"` in addition to `<> invalid` — a `for each` over a non-array JSON value crashes at runtime and `bsc` does NOT flag it. Apply at BOTH the assignment site and any iteration site.
- **[convention]** Each NEW component `.xml` must `<script>`-include its FULL source closure IN ORDER (`Storage`, `Utilities`, `ApiClient`, `AppContext`, then its own `pkg:/components/<Scene>.brs`) — a component scope does NOT auto-include `pkg:/source`. A missing include is a runtime "function not found" that `bsc` does NOT catch.
- **[gotcha]** Cross-component callable subs MUST be declared in the component `<interface>` as `<function name="LoadFoo"/>` — a `scene.LoadFoo(...)` call from another scene fails at runtime without it and `bsc` does NOT catch it. A scene a PARENT creates+appends+focuses and self-loads on `Init` needs NO `<interface><function>`; only entry-points invoked as `scene.Method(...)` from another scene require declaration. Verify caller arg arity/order matches the callee signature.
- **[convention]** Stringify ints the repo way: `str(Int(x)).trim()` (matches `LibraryScene` `str(item.year).trim()`, `Utilities` EpisodeCaption, ApiClient `str(limit).trim()`). Before committing an appended helper, check the file's existing EOF (e.g. `tail -c | xxd`) and match it — `Utilities.brs` has NO trailing newline on master, so preserve that to keep the diff minimal.
- **[pattern]** Verify a scene against the bsc gate with `npx brighterscript@0.72.5 --project bsconfig.json` and grep the log for `error|warn` (EXIT=0 + "clean" = pass). This is the ONLY real static gate — `make lint`/`make test`/CI never fail.
